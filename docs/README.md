# Documentation

Use the [practice website](https://mbianchidev.github.io/engineering-interviews/) to browse questions and rehearse answers.

## For people practicing

The [practice guide](practice.md) covers topic browsing, timed and untimed rounds, saving and clearing answers, self-evaluations, troubleshooting, the STAR method, and useful resources. No local installation is needed for the hosted website.

## For contributors

The [developer guide](../SETUP.md) covers Node.js prerequisites, local setup, the stack and data flow, validation commands, question authoring, and static-site deployment. Existing setup instructions stay in that guide rather than being duplicated here.

Read [CONTRIBUTING.md](../CONTRIBUTING.md) before opening a pull request. Agents must also read [AGENTS.md](../AGENTS.md), including the dependency-backport maintenance TODO.

Community expectations and reporting routes are documented in the [Code of Conduct](../CODE_OF_CONDUCT.md), [security policy](../SECURITY.md), and [accessibility guidance](../ACCESSIBILITY.md). Use the security policy's private channel for vulnerabilities rather than public issues.
