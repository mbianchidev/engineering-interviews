# Security policy

## Supported versions

Security fixes cover the current `main` branch and the practice website deployed from it. Historical commits, forks, and older deployments are not supported security-release lines. There are no published versioned releases.

When possible, confirm that an issue still affects the current `main` branch before reporting it.

## Report a vulnerability privately

Use [GitHub private vulnerability reporting](https://github.com/mbianchidev/engineering-interviews/security/advisories/new), also available under **Security > Report a vulnerability** in this repository. Private vulnerability reporting is enabled.

Do not publish vulnerability details in public issues, pull requests, or discussions before coordinated disclosure. Reports should include:

- The affected commit or deployed page and relevant browser/runtime versions.
- A description of the vulnerability, impact, and any prerequisites.
- Minimal reproduction steps or a proof of concept using synthetic data.
- Redacted logs or screenshots when they help explain the issue.

Do not include credentials, real interview responses, or other people's personal data. Keep reproduction work confined to systems and test data you are authorized to use.

## Response and disclosure

The project maintainer reviews reports on a best-effort basis. There is no guaranteed acknowledgment, update, or fix deadline. Keep follow-up information in the private GitHub report; the maintainer may request clarification, assess impact, and discuss a fix or mitigation there.

Keep details private while a fix is prepared. Once a fix is available, the maintainer and reporter will coordinate the public disclosure and agree on which details to publish. This policy does not set a fixed disclosure deadline.

## Other reports

Use [issues](https://github.com/mbianchidev/engineering-interviews/issues) for non-sensitive bugs and [accessibility barriers](ACCESSIBILITY.md#report-an-accessibility-barrier). For conduct reports, follow [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md#reporting-an-issue).
